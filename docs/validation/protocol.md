## 开始前登记

填写项目 URL/仓库、基线 commit、目标用户、关键流程、具体问题、可接受结果、技术栈、测试数据、桌面/移动视口。排除需要真实付款或破坏生产数据的操作，使用可重置测试环境。同时登记各组操作者与该项目的关系和接触时长，见下方 G2 的先验熟悉度条款。

登记三组共同的模型版本、推理设置、工具与上下文包、墙钟时间上限、模型费用上限、重试规则、测试步骤。具体预算根据项目确定，必须在第一次运行前填写。缺模型配置或费用证据时标注无法公平比较，不补估为真实观测。

## G1：定位与 $20 意愿

招募 5 位符合定位的开发者，记录匿名 ID、独立开发背景、现有产品、近期真实任务。不要用代理或模型模拟真实访谈。

1. 单独展示 product-direction.md 中“给目标用户看的版本”，不展示内部方向、竞品对比或创业愿景。
2. 问：“你理解这项服务替谁解决什么问题？一次会拿到什么？”保存原话，先不纠正。
3. 问：“你最近什么时候遇到过类似问题？当时怎样处理？”
4. 问：“按刚才这个范围，20 美元一次，你会购买吗？为什么？”记录 yes/no/conditional；条件单列。
5. 问：“你最担心什么，或觉得哪部分不值得？”结束后再解释误解，解释后的答案不能替换最初答案。

沿用 #1：至少 4/5 能准确复述对象与一次交付物。#12 未指定意愿人数门槛，本轮只报告 yes/no/conditional 分布，不擅自把 3/5 意愿当成已付费或通过。真正支付仍按 #8 的试点验证。G1 结果进入人工决策，不单独自动放行工程。

## G2：三组手工对照

|组|输入与工作方式|
|---|---|
|A|Codex，通用但充分的任务说明，无专用 UX Skill|
|B|同模型 Codex + 高质量 UX Skill，允许其自带诊断、工具和迭代 Loop|
|C|人工扮演服务：诊断、排序、指挥 Codex 修改、渲染、复评|

固定上下文包含业务目标、核心任务、同一具体问题、仓库起点、约束和测试步骤。B 的 Skill 在运行前记录来源、版本/内容哈希和选择理由，不能挑一个明显弱的 Skill。三组从干净的同一 commit 开始，独立会话/分支，不能读取其他组的修改与结论。随机登记运行顺序；尽量由独立操作员执行，若同一人看过前组结果，记录知识迁移偏差。

**项目先验熟悉度是与知识迁移不同的一种偏差，单独登记。** A、B 两组只拿到固定上下文包，而 C 组操作者若参与过该项目的开发，会带入上下文包里没有的代码结构、历史决策和已知坑位，系统性抬高 C。

优先选择 C 组操作者没有参与过开发、也没有长期使用过的项目。做不到时，在开始前登记操作者与该项目的关系（开发者／长期用户／仅阅读过文档／完全陌生）、接触时长，以及上下文包之外实际用到的项目知识；该次结论按已知偏差折价，写作“存在先验优势的单案例观察”，不进入跨项目复现证据。

三组操作者若不是同一人，分别登记各自的项目关系，避免把偏差只算在 C 组头上。

每组记录运行起止、开发者人工分钟、服务运营者人工分钟、模型/工具成本、失败重试、diff、渲染截图及原任务复测。C 组运营者时间不能伪装成零成本自动化。达到共同预算就停止，失败也交付失败记录，不只挑最优的一次。

匿名评审材料使用随机代号 X/Y/Z（映射单独保存），去除组名与操作日志，但保留相同视口、流程、可操作结果和证据。由 5 位不知道来源的评审分别对 C 与 B 的任务完成质量、是否新增阻断回归进行比较，允许平局和无法判断。A 是补充参照，不能只挑 A 作为宣传基线。

保留 #10/#12 门槛：人工介入中位时间降低 ≥30%，或至少 4/5 盲评偏好 C；且无新增关键回归。单次三组执行只能使用盲评分支作探索性判断；时间只报告原始值，不能称中位数证据。若选择时间分支，提前登记至少 3 次独立成对运行，以开发者人工时间中位数计算 (B-C)/B；B=0 时该分支不可计算。运营者时间另行披露并进入 G3。不能看完结果再选择补跑次数。

一项目的通过结论写作“该案例初步达标”，后续跨项目复现仍在 #10。评审不足或执行条件不一致则为证据不足，不判定服务胜出。

## G3：同次 C 组交付成本

保留账单或工具使用导出作为来源，记录币种与价格日期。模型按 input/output/cache 的实际计价计算；浏览器执行、渲染、存储、失败重试、支付费用分别记录。套餐额度无法拆分时报告区间与未知，不能把未知计零。

运营者人工成本 = 分钟数 / 60 × 事先声明的小时成本。用户自己的时间单列为节省指标。以美元核算时登记汇率来源与日期；无换汇则无需引入汇率。

总变动成本 = 模型 + 执行/渲染 + 存储 + 人工 + 支付费用 + 其他实际变动成本。

单次贡献 = 实收金额 - 退款 - 总变动成本；贡献率 = 单次贡献 / 实收金额。尚未收费时只输出“按 $20 假设的贡献”，不得称实际收入或完整公司毛利。

若成本超过 $20，列出 #1 服务范围、#7 轮次与重构边界、#8 定价/交付包的具体修改；不能通过漏计人工使其通过。
