# AI Product Designer · 前置验证

面向已有可运行网站的独立开发者，探索设计后的体验诊断、优先级判断、页面修改或重新生成，以及真实运行验证。

当前处于手工前置验证阶段，尚无上线产品。根据 [#12](https://github.com/ShuaiMXu/design-governance-proposal/issues/12)，先验证定位与付费意愿、相对 Codex + 高质量 UX Skill 的增量、单次交付成本，再决定 MVP 工程。
